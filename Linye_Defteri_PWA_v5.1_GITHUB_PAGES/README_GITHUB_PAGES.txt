LINYE DEFTERI PWA v5.1 - GITHUB PAGES

Bu paket GitHub Pages icin hazirdir.

1) ZIP'i klasore cikarin.
2) GitHub'da yeni PUBLIC repository olusturun (ornegin: linye-defteri).
3) Repository icinde Add file > Upload files secin.
4) Bu klasorun ICINDEKI tum dosya ve klasorleri surukleyin. ZIP'in kendisini yuklemeyin.
5) Commit changes.
6) Settings > Pages > Build and deployment > Source: Deploy from a branch.
7) Branch: main, Folder: /(root) > Save.
8) 1-3 dakika sonra verilen https://KULLANICI.github.io/linye-defteri/ adresini acin.
9) Android Chrome > menu (⋮) > Uygulamayi yukle / Ana ekrana ekle.

Not: GitHub Pages varsayilan github.io adreslerinde HTTPS otomatik gelir.
